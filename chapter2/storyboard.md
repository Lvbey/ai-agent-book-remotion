## 2. 旁白节奏与声音设计

建议叙述速度约 220–250 个汉字/分钟（按中文教育科普语气）。镜头平均 7–10 秒，文字以一句或两句为限。实际录音完成后以音轨为准同步微调字幕时点。

声音建议：
- 背景音乐为轻打击、木质音色与柔和合成器，不使用强烈赛博朋克音色。
- 信息卡入位、工具调用、结果回流可使用低音量、短时长拟音；所有音效都应支持因果，不作为持续装饰。
- S23–S25 缓存揭示处先短暂停顿，再用较轻的低音提示解释机制。
- S38 记忆句后减少音符并留出 1 秒停顿。

- [x] 从具体失败场景过渡到概念和机制，再收束到可复述的工程原则。
- [x] 不把工具请求描述成工具已执行。
- [x] 不将缓存、提示词和上下文训练混为一谈。
- [x] 不把摘要说成无损压缩。
- [x] 不将上下文窗口溢出与上下文腐化合并成一个现象。
- [x] 缓存处使用“有机会复用”“取决于服务实现”等限定表达。
- [x] 视觉动作都服务于知识传递，无随机漂浮、无意义粒子或长段纯文字镜头。
- [ ] 仍需在 Remotion Studio 按镜头检查并依据实际配音进行最终剪辑微调。
