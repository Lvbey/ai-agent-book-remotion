# 视觉系统（深色未来感 / 时间线）

所有数值都是 **1280×720 设计坐标**。舞台整体等比缩放，任何窗口都是一屏一页，永远不出现滚动条。

## 1. 色彩

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#05070c` | 画布底 |
| `--ink` | `#e9f0ff` | 正文主色（标题） |
| `--ink2` | `#a9b8d6` | 段落正文 |
| `--dim` | `#6a7a9a` | 注释、卡片说明、页脚 |
| `--cyan` | `#4fe3ff` | 主强调：小节点、chip、当前小节 |
| `--violet` | `#8b7bff` | 次强调：标题第二行的 `em` |
| `--amber` | `#ffb46b` | 警示 / 注意 / 代码行号 |
| `--line` | `rgba(140,170,220,.14)` | 卡片描边 |
| `--line2` | `rgba(140,170,220,.07)` | 细分隔线 |

规则：
- **一页最多两个强调色。** 青色是"结构"，紫色是"观点"，橙色只给"注意/边界"。第三个橙出现=这一页在喊救命。
- 渐变只用在标题的 `em` 上（`linear-gradient(100deg, cyan, violet)`），不要给正文加渐变。
- 背景是三层径向渐变 + 32px 网格 + 暗角，已封装在 `#bg / #grid / #vign`，不要另画。

## 2. 排版

| 元素 | 字号 / 行高 | 说明 |
|---|---|---|
| 封面英文主标 `.cover-en` | 112px / 0.94 | 两行断开，全大写 |
| 封面中文 `.cover-cn` | 40px / 1.25 | 一行，字距 .1em |
| 分隔页标题 `.part h2` | 58px / 1.14 | 第一行实色，第二行 `<em>` 渐变 |
| 正文标题 `h2.h2` | 44px / 1.2 | 同上 |
| 导语 `.lede` | 15.5px / 1.8 | 最多两行，`max-width:840px` |
| 卡片标题 `h3` | 16px / 1.35 | |
| 卡片正文 `p` | 12.5px / 1.62 | **最多三行** |
| 注释 `.note` | 13px / 1.62 | 带左侧色条 |
| 元信息 `.chip` | 11.5px 等宽 / 字距 .16em | 全大写 |

字体栈已经内置：`Cascadia Code / SF Mono → Consolas`；中文 `Segoe UI / PingFang SC / 微软雅黑`。
**不要引入任何 webfont 或外链**，离线打开也要一模一样。

## 3. 版心与安全区

```
画框 1280 × 720
├─ padding-left/right : 78px      → 内容列 1124px
├─ padding-top        : 58px
├─ padding-bottom     : 106px     → 正文底边 614，其下是 HUD 刻度条
└─ 框线 .frame inset 14px（装饰，别往里放东西）
```

- **正文内容列宽 1124px。** 任何 `max-width` 只能 ≤1124；一旦写了 1020 这种数字，卡片右缘就会比标题短一截，肉眼立刻看出"歪"。
- 底部 614 以下是 HUD 的地盘，放东西一定被压。
- 装饰性水印 `.ghost` 例外：它允许出血，但右缘仍要留在 1202（=1280−78）以内，否则画框外的部分被裁，看上去像"没做完"。

## 4. 动效

- 所有入场元素加 `.reveal`，用 `style="--d:.08s"` 递增延迟，步长 **0.04–0.06s**，一页最多排到 `.46s`。
- 只做 `opacity + translateY(16px)`，禁止旋转、缩放、弹跳。
- 页面切换：非当前页 `translateX(±52px)`，`.62s cubic-bezier(.22,.61,.36,1)`。
- 有一层 `settle()` 兜底：1.4s 后强制把当前页所有 `.reveal` 置为可见。截图脚本就是靠它拿到稳定画面。

## 5. 固定装饰（不要重复实现）

| 元素 | 位置 | 含义 |
|---|---|---|
| `.progress` | 顶部 2px 渐变条 | 全局进度 |
| `.frame` | 四角取景框 | 画面边界提示 |
| `.slide:before/after` | 左侧竖脊 + 发光节点 | 时间线隐喻，串起整章 |
| `.rail` | 底部刻度条 | 每一页一个刻度，按小节分色，可点击跳转 |
| `.pager` | 右下 `03 / 18` | 当前页 / 总页数，JS 自动统计 |

刻度条分色靠 `data-tier`：`""`(无色，封面/章节页) / `a`(青) / `b`(紫) / `c`(橙，小结与结尾)。
同一个二级小节内的所有页用同一个 tier，读起来就是一条连续的时间线。
